# Sprint_m API Tests

Проект содержит автотесты для проверки API сервиса объявлений https://qa-desk.education-services.ru/.

## Описание проекта

В проекте реализованы API-тесты на Python с использованием `pytest` и `requests`.

Проверяется основной пользовательский сценарий:

- регистрация пользователя;
- авторизация пользователя;
- создание объявления;
- редактирование объявления;
- удаление объявления;
- проверка ограничений доступа для чужого пользователя.

## Стек технологий

- Python 3.8+
- Pytest
- Requests
- Requests Toolbelt
- Allure Pytest
